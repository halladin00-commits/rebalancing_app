# 주간 투자일기 초안 작성

펨코 주식갤에 올릴 주간 투자일기 초안을 작성한다.

## 사용 방법

스크린샷을 첨부하거나 수치를 직접 알려주면 된다.
첨부 없이 호출하면 수치 입력을 요청한다.

## 포트폴리오 구조 (고정)

**위탁계좌**: TIME 미국나스닥100액티브 + TIGER 미국배당다우존스 2종목
**ISA계좌**: 테마 ETF 10종목 균등 10% 분산

## 글 작성 규칙

### 제목 형식
`MM/DD 주간 투자일기 | [이번 주 한 줄 특징]`

예시:
- `5/23 주간 투자일기 | 나스닥 덕에 흐뭇한 한 주`
- `5/30 주간 투자일기 | 변동성 한 주, 비중 조절 완료`

### 본문 구조

```
[간단한 시황 한 줄]

[ 위탁계좌 ]
보유 종목 현황 (주수 포함)
주간 수익률/금액
리밸런싱 했으면 내용 기재 (매도 N주 / 매수 N주)

[ ISA계좌 ]
테마 ETF 10종목 균등 분산 운용
주간 수익률/금액
이번 주 눈에 띄는 종목 1~2개 언급

[ 전체 ]
총자산 / 평가수익률

짧은 코멘트 (향후 운용 계획, 한 줄)
```

### 마지막 앱 홍보 문단 (항상 포함, 고정 문구)

```
---

포트폴리오 비중 계산이랑 주간/월간 수익률 추적이 귀찮아서 직접 앱 하나 만들어서 씀. 리밸런싱 수량 자동 계산에 결산 이미지 뽑는 것도 되고 생각보다 쓸만함. 구글 플레이에서 Rebalancing 검색하면 나옴. 무료.
```

### 말투 규칙
- 반말, 간결하게
- 숫자는 만원 단위 표기 (예: +1,797만원)
- % 수익률 앞에 +/- 명시
- 불필요한 이모티콘 없음
- 너무 자랑스럽지 않게, 담담하게

### 첨부 이미지 추천 (글 마지막에 안내)
결산 이미지 (위탁 + ISA) 첨부 추천 — 포트폴리오 실적과 앱 기능이 자연스럽게 같이 보임
