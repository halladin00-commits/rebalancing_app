## 저장 형식 변경 — 마지막 조정 시각 (`5aba0ea`, 승인받음)

`Portfolio.lastRebalancedAt` (epoch ms, nullable)을 더했다.

**왜**: 리밸런싱 규율은 밴드(허용 편차)와 기간(반년·1년) 둘 중 하나이거나

**언제 찍나**: 조정 제안에서 **일괄 기록할 때만.** 거래 하나를 따로 넣는

**옛 데이터**: 키가 없으면 null → 화면은 `조정 기록 없음`. 없는 날짜를
지어내지 않는다. 실기기에서 사장님 실제 데이터로 확인했다.

**주의**: 앞으로 `Portfolio`에 필드를 더할 때 `toJson`·`fromJson`·

### 에뮬레이터 RAM을 3GB로 올렸다 (2026-08-31)

`System UI isn't responding`이 반복된 원인을 재 보니 **CPU가 아니라
메모리**였다. AVD가 2GB인데 1.89GB가 차 있었다 — 디버그 빌드 앱만
292MB를 쓴다. CPU는 스스로 회복했지만 메모리는 설정이라 안 낫는다.

`~/.android/avd/Medium_Phone.avd/config.ini`의 `hw.ramSize` 2048 → 3072
(백업: `config.ini.bak`). 가용 메모리 120MB → **1.89GB**.
호스트가 16GB라 4GB는 빌드 중에 조여서 3GB로 했다.

재시작 명령:
```
"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd Medium_Phone_API_36.1 -no-snapshot-save -no-boot-anim
```

**교훈 둘**
- **TalkBack을 켜면 이 에뮬레이터는 회복이 안 된다.** 접근성 확인은 실기기에서.
- WORK_STATE에 이미 적혀 있던 **「빌드와 동시에 돌리면 죽는다」를 지킨다.**
  오늘 빌드를 20번 넘게 돌리면서 계속 어겼다.

### 1. 결산 탭 빈 상태 안내 — ✅ 완료 (2026-08-24)

에뮬레이터를 비행기 모드로 두고 결산 탭에 들어가니 **헤더가 거의 비어 있었다.**
기간 손익·수익률 자리에 작은 회색 막대만 남고, 왜 비었는지 설명이 없다.
`해당 기간 보유 종목 없음`만 아래에 뜬다.

- 원인: 결산은 과거 주가를 API로 받아야 계산된다. 네트워크가 없으면 계산 불가.
- 문제: **네트워크가 끊긴 사용자가 결산 탭을 열면 고장 난 화면처럼 보인다.**
  `시세를 받지 못해 계산할 수 없습니다 · 다시 시도` 같은 안내가 필요하다.
- 확인 중이던 것: 네트워크를 켜고 다시 들어가 정상 상태와 비교하는 것까지 했고,
  결과 스크린샷은 확인하지 못했다. **네트워크 켠 상태에서 먼저 재현 여부를 확인할 것.**
- 손댈 파일: `lib/screens/all_settlement_screen.dart`(헤더),
  `lib/screens/portfolio_settlement_screen.dart`

## 개발 환경 요령

### 빌드
```
export GRADLE_USER_HOME=D:/gradle_fresh
flutter build apk --release
```

### 폰에 설치할 때 (서명 우회)
폰에 **디버그 키로 서명된** 앱이 깔려 있어 업로드 키 서명 APK가 안 붙는다.
`key.properties`를 잠시 옮겨 디버그 서명으로 빌드한 뒤 **반드시 되돌린다.**
```
mv android/key.properties android/_key.properties.aside
flutter build apk --release
mv android/_key.properties.aside android/key.properties   # 절대 빠뜨리지 말 것
```
> 근본 해결은 폰의 앱을 지우고 업로드 키 버전으로 한 번 새로 깔기.
> 데이터가 지워지므로 사용자 동의가 필요하다(백업 → 삭제 → 설치 → 복원).

### 에뮬레이터
- **빌드와 동시에 돌리면 죽는다.** 빌드를 먼저 끝내고 띄운다.
- 죽으면 `-wipe-data`로 복구 (자세한 절차는 design_spec.md)
- **검증할 때는 비행기 모드를 켠다** — AdMob이 즉시 실패해 ANR이 안 난다.
  단 결산 탭은 네트워크가 필요하다(위 1번 항목).
- **화면 확인은 `sh tools/shot.sh <이름>`으로 한다.** 캡처를 480px로 줄여 저장한다.
  원본(1080px)을 그대로 읽으면 토큰을 3~4배 먹는데, 480px로도 레이아웃은 다 읽힌다.
  480px에서 잰 좌표 **x2.25**가 `adb shell input tap`에 넣을 좌표다.
- **`uiautomator dump`는 Flutter에서 안 통한다** — 캔버스에 그려서 위젯이 안 잡힌다.
  UI 트리를 텍스트로 뽑아 캡처를 아끼려 했으나 빈 결과만 나온다. 확인은 캡처로 한다.
- 탭이 어긋나면 앱이 아직 뜨는 중일 수 있다. 긴 이동은 중간에 한 번 찍어 확인한다.
- **첫 진입 화면을 보려면 앱 데이터를 지워야 한다. 지우기 전에 백업한다** —
  디버그 빌드는 `run-as`로 앱 내부를 만질 수 있다.
  ```sh
  # 백업
  adb shell run-as com.xaxavoo.rebalancing cat shared_prefs/FlutterSharedPreferences.xml > prefs.xml
  adb shell pm clear com.xaxavoo.rebalancing
  # 복구 (run-as는 /sdcard를 못 읽으므로 표준입력으로 넣는다)
  base64 -w0 prefs.xml > prefs.b64
  adb shell "run-as com.xaxavoo.rebalancing sh -c 'base64 -d > shared_prefs/FlutterSharedPreferences.xml'" < prefs.b64
  ```
  Git Bash에서 `/sdcard/...` 경로는 `MSYS_NO_PATHCONV=1`을 붙여야 안 망가진다.

### 도구 주의
- Bash 히어독에서 Dart/JSON을 쓰면 **백슬래시가 먹힌다.** `chr(92)`를 쓰거나
  Write 도구로 파일을 만든다.
- `flutter analyze` 확인은 `grep -iE "error -|warning -"`로. `^\s+(error|warning)`은
  warning 줄을 놓친다(이것 때문에 경고 9개가 쌓인 걸 늦게 발견했다).
