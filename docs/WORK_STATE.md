### 1. 결산 탭 빈 상태 안내 — ✅ 완료 (2026-08-24)

에뮬레이터를 비행기 모드로 두고 결산 탭에 들어가니 **헤더가 거의 비어 있었다.**
기간 손익·수익률 자리에 작은 회색 막대만 남고, 왜 비었는지 설명이 없다.
`해당 기간 보유 종목 없음`만 아래에 뜬다.

- 원인: 결산은 과거 주가를 API로 받아야 계산된다. 네트워크가 없으면 계산 불가.
- 문제: **네트워크가 끊긴 사용자가 결산 탭을 열면 고장 난 화면처럼 보인다.**
  `시세를 받지 못해 계산할 수 없습니다 · 다시 시도` 같은 안내가 필요하다.
- 확인 중이던 것: 네트워크를 켜고 다시 들어가 정상 상태와 비교하는 것까지 했고,
  결과 스크린샷은 확인하지 못했다. **네트워크 켠 상태에서 먼저 재현 여부를 확인할 것.**
- 손댈 파일: `lib/screens/all_settlement_screen.dart`(헤더),
  `lib/screens/portfolio_settlement_screen.dart`

아래 셋은 **앱에 없는 데이터**를 요구한다. 지금 만들면 숫자를 지어내야 한다.

| 시안 | 필요한 것 |

| v22b 손익 구성 표 | **배당**을 거래 유형으로. 실제 **수수료·세금** 기록 |

## 개발 환경 요령

### 빌드
```
export GRADLE_USER_HOME=D:/gradle_fresh
flutter build apk --release
```

### 폰에 설치할 때 (서명 우회)
폰에 **디버그 키로 서명된** 앱이 깔려 있어 업로드 키 서명 APK가 안 붙는다.
`key.properties`를 잠시 옮겨 디버그 서명으로 빌드한 뒤 **반드시 되돌린다.**
```
mv android/key.properties android/_key.properties.aside
flutter build apk --release
mv android/_key.properties.aside android/key.properties   # 절대 빠뜨리지 말 것
```
> 근본 해결은 폰의 앱을 지우고 업로드 키 버전으로 한 번 새로 깔기.
> 데이터가 지워지므로 사용자 동의가 필요하다(백업 → 삭제 → 설치 → 복원).

### 에뮬레이터
- **빌드와 동시에 돌리면 죽는다.** 빌드를 먼저 끝내고 띄운다.
- 죽으면 `-wipe-data`로 복구 (자세한 절차는 design_spec.md)
- **검증할 때는 비행기 모드를 켠다** — AdMob이 즉시 실패해 ANR이 안 난다.
  단 결산 탭은 네트워크가 필요하다(위 1번 항목).

### 도구 주의
- Bash 히어독에서 Dart/JSON을 쓰면 **백슬래시가 먹힌다.** `chr(92)`를 쓰거나
  Write 도구로 파일을 만든다.
- `flutter analyze` 확인은 `grep -iE "error -|warning -"`로. `^\s+(error|warning)`은
  warning 줄을 놓친다(이것 때문에 경고 9개가 쌓인 걸 늦게 발견했다).
