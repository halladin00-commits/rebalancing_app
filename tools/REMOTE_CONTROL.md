# 출장 중 폰에서 이어서 작업하기

`tools/start_remote_control.cmd`가 하는 일과 쓰는 법.

## 이게 뭔가

이 PC에서 돌고 있는 Claude Code 세션을 **폰에서 그대로 이어받는** 기능이다
(Remote Control). 폰은 화면 역할만 하고, 실제 작업은 이 PC에서 돈다.

그래서 **Flutter 빌드, 에뮬레이터, 서명 키가 전부 그대로 쓰인다.**
클라우드 세션(claude.ai/code)에는 Android SDK가 없어 빌드를 못 한다.

확인 요청(권한, 선택지)도 폰으로 전달돼 폰에서 고를 수 있다.

## 쓰는 법

### 처음 한 번 (사람이 직접)

1. VS Code 터미널 열기 — `Ctrl` + `` ` ``
2. 붙여넣고 Enter:
   ```
   D:\claude_code\rebalancing_app\tools\start_remote_control.cmd
   ```
3. 25초 뒤 `Enable Remote Control? (y/n)` → **`y`**
   (이 PC를 밖에서 조작하게 허용하는 보안 확인이라 사람이 눌러야 한다)
4. 세션 주소가 뜬다. **스페이스바**를 누르면 QR 코드
5. 폰에서 **Claude 앱 → Code 탭** → 이 세션이 보인다

**이 창은 닫지 말 것.** 닫으면 폰에서 오프라인으로 보인다.
중지는 창 안에서 `Ctrl+C`.

### 그 다음부터

시작 프로그램에 등록돼 있어 **재부팅 후 로그인하면 자동으로 뜬다.**
바로가기 위치:
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Claude Remote Control.lnk`

## 스크립트가 대신 해주는 것

| 상황 | 처리 |
| --- | --- |
| 부팅 직후 네트워크가 아직 안 붙음 | 25초 기다린 뒤 시작 |
| 네트워크가 10분 이상 끊겨 프로세스가 종료됨 | 60초 뒤 자동 재시작 |

## 남은 빈틈

**재부팅 후 로그인 화면에서 멈추면 시작 프로그램이 안 돈다.**
해외에서는 로그인해 줄 사람이 없다. 둘 중 하나로 막는다:

- **Windows Update 일시 중지** (설정 → Windows Update → 최대 5주)
  → 재부팅 자체가 안 생긴다. 보안상 더 안전한 쪽.
- **자동 로그인 켜기** (설정 → 계정 → 로그인 옵션 →
  "업데이트 후 자동으로 로그인하여 설정 완료")
  → 편하지만 PC를 물리적으로 만질 수 있는 사람은 잠금 없이 들어온다.

## 이것마저 안 될 때 (백업)

PC가 아예 접속 불가면 **claude.ai/code에서 클라우드 세션**을 연다.
GitHub의 `redesign-ui` 브랜치에 작업이 올라가 있으므로 코드 수정·리뷰는 가능하다.
다만 **빌드와 에뮬레이터 확인은 못 한다** — PC로 돌아온 뒤에 한다.

## 주의

- 배치 파일은 **영문 ASCII + CRLF 줄바꿈**이어야 한다.
  한글을 넣거나 LF 줄바꿈으로 저장하면 CMD가 명령어를 쪼개 읽어
  (`timeout` → `time` + `out`) 에러가 쏟아진다. 한글 설명은 이 파일에 둔다.
